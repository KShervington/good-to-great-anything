# Example: Linewright (fictional)

Linewright is a **fictional** solo-founder desktop app for subtitle timing. It was written as a test case for the skill's evaluation. Any resemblance to a real product is coincidental.

- [dossier.md](dossier.md): the input, written as the founder's quarterly notes to self.
- [output.md](output.md): one unedited run of the skill (autonomous mode, no web research or memory available), from the held-out evaluation.
- [report.html](report.html): the same run shown as the guided report page. Download it and open it in a browser.
- [report-data.json](report-data.json): the data behind the page, condensed from `output.md` by hand. Rebuild with `python tools/build_report.py examples/linewright/report-data.json examples/linewright/report.html`.

What to look for:

- **The verdict:** good, not yet great. It names the most urgent brutal fact: renewals are falling below the founder's own model, while the main reason people buy is about to become free.
- **The Hedgehog:** it moves the product's identity away from its headline feature (auto-align) to the thing studios actually pay for (passing delivery specs the first time).
- **The stop-doing list:** it declines the tempting creator spin-off and explains why, kindly.
- **Decline risks:** each has an early warning sign and the evidence that would clear it.
